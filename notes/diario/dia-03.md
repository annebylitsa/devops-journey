# Diario día 3

## Qué aprendí
- Aun más comandos nuevos
- Qué son las ramas en un proyecto git
- La lógica detrás de las ramas
- Qué es una PR y su ciclo

## Práctica
- He aprendido a crear ramas nuevas, moverme por ellas, fusionarlas y eliminarlas tanto en la VM como en GitHub directamente
- He utilizado más en detalle GitHub
- He creado conflictos para aprender a resolverlos
- He practicado a hacer Pull Requests

## Errores y cómo los resolví
- He descubierto que si ejecuto un comando cuya respuesta es mucho texto, scrolleando puedo perderme entre letras y números para siempre. A menos que escriba las letras mágicas ":q" y pulse Enter. Esa fue la solución.

## Resumen del día
- Hoy ha sido un día con información un tanto pesada. He aprendido nuevos comandos y, algunos de ellos, no terminan de tener sentido para mi (como git push -u). Por otro lado, también he tenido ejercicios prácticos entretenidos. He podido ver como con VSCode puedo resolver conflictos de forma sencilla y he podido romper el hielo con GitHub que ahora me parece menos lioso y cada vez más familiar.
