# Linux Filesystem

He visto una cantidad obscena de directorios hoy, así que sólo apuntaré algunos de ellos en este archivo para no pasarme la tarde escribiendo.

## Directorios:
- /etc: es el que contiene todas las configuraciones de archivos del sistema, todo debe ser un text legible en este directorio
- /var: donde se almacena la dara que puede cambiar (databases, spool files, user mail...)
- /home: es común que cada usuario tenga su propio directorio dentro de /home donde puedan escribir archivos
- /usr: probablemente el directorio más grande de Linuz, contiene todos los programas y archivos de soporte utilizados por los usuarios del sistema
- /opt: utilizado para instalar software opcional
- /tmp: utilizado para almacenamiento temporal que suele ser vaciado cada vez que se reinicia el sistema
